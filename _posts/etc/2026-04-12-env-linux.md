## Ubuntu에서 fcitx5로 한글 입력기 통일 & 우측 Alt로 한영 전환 설정

### 배경

Ubuntu 24.04 GNOME 환경에서 ibus-hangul과 fcitx5-hangul이 동시에 설치되어 입력기가 꼬이는 문제가
있었다. 특히 Cursor 같은 Electron 기반 에디터에서 ibus 사용 시 한글 조합이 씹히는 현상이 있어서
fcitx5로 통일하기로 결정했다.

### 1단계: 현재 상태 확인

#### 설치된 한글 입력기 확인

```shell
dpkg -l | grep -iE 'ibus-hangul|fcitx.*hangul'
```

#### 현재 입력기 환경변수 확인

```shell
echo "GTK_IM_MODULE=$GTK_IM_MODULE"
echo "QT_IM_MODULE=$QT_IM_MODULE"
echo "XMODIFIERS=$XMODIFIERS"
```

#### im-config 현재 설정

```shell
im-config -m
```

### 2단계: ibus-hangul 제거

```shell
sudo apt remove -y ibus-hangul
```

### 3단계: 환경변수를 fcitx로 변경

```shell
~/.bashrc (또는 ~/.profile, ~/.xprofile)에서 아래처럼 수정한다.
```

```shell
# Before
export GTK_IM_MODULE=ibus
export QT_IM_MODULE=ibus
export XMODIFIERS=@im=ibus

# After
export GTK_IM_MODULE=fcitx
export QT_IM_MODULE=fcitx
export XMODIFIERS=@im=fcitx
```

### 4단계: fcitx5를 기본 입력기로 지정

```shell
im-config -n fcitx5
```

### 5단계: 우측 Alt로 한영 전환 설정

```shell
~/.config/fcitx5/config 파일의 [Hotkey/TriggerKeys] 섹션을 수정한다.
```

```
# Before
[Hotkey/TriggerKeys]
0=Control+space
1=Zenkaku_Hankaku
2=Hangul

# After
[Hotkey/TriggerKeys]
0=Alt_R
1=Hangul
2=Control+space
```

> GUI로 하려면 fcitx5-configtool 실행 → Global Options → Trigger Input Method에서 우측 Alt 키 입력으로 재설정 가능.

### 6단계: 재로그인

설정을 반영하려면 로그아웃 후 재로그인 또는 재부팅한다.

# 확인

```shell
echo $GTK_IM_MODULE  # fcitx 출력되어야 함
pgrep -a fcitx5       # fcitx5 데몬 실행 확인
```

## VS Code에서 우측 Alt 키 누르면 File 메뉴로 포커스 가는 문제 해결

VS Code에서 코딩 중 우측 Alt 키를 누르면 상단 메뉴바의 File 탭으로 포커스가 이동하는 현상. 한국 키보드에서 한/영 전환 키로 쓰이는 우 Alt 위치라 자주 눌리게 되는데, 그때마다 메뉴바로 포커스가 빼앗겨서 작업 흐름이 끊긴다.

### 해결 방법

settings.json을 열어서 아래 설정을 추가한다.

설정 파일 열기

```
Ctrl + Shift + P → Preferences: Open User Settings (JSON) 선택
```

설정 추가

```json
{
"window.customMenuBarAltFocus": false,
"window.enableMenuBarMnemonics": false
}
```

window.customMenuBarAltFocus - Alt 단독 입력 시 메뉴바로 포커스 이동 차단
window.enableMenuBarMnemonics - Alt+F, Alt+E 등 니모닉 단축키 비활성화

## 리눅스 시스템 언어를 한국어로 변경하기

### 1. 현재 로케일 확인

```shell
locale              # 현재 적용된 로케일
locale -a | grep ko # 설치된 한국어 로케일 목록
```

출력에 ko_KR.UTF-8이 없다면 설치가 필요합니다.

### 2. 시스템 전역 변경 (Ubuntu/Debian 기준)

모든 사용자와 시스템 메시지에 적용되는 방법입니다.

#### 2-1. 한국어 언어팩 및 폰트 설치

```shell
sudo apt update
sudo apt install language-pack-ko fonts-noto-cjk
```

#### 2-2. 로케일 생성

```shell
sudo locale-gen ko_KR.UTF-8
```

#### 2-3. 기본 언어 설정

```shell
sudo update-locale LANG=ko_KR.UTF-8 LANGUAGE=ko_KR:ko LC_ALL=ko_KR.UTF-8
```

또는 /etc/default/locale 파일을 직접 편집해도 됩니다.

```
LANG=ko_KR.UTF-8
LANGUAGE=ko_KR:ko
LC_ALL=ko_KR.UTF-8
```

#### 2-4. 적용

로그아웃 후 재로그인 또는 재부팅.

```shell
sudo reboot
```
