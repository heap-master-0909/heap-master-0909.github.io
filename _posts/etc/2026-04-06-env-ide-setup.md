CLion·VS Code를 같이 쓸 때 맞춰 두면 편한 단축키 모음이다. JetBrains 계열은 **Settings → Keymap**에서 아래 이름으로 검색해 동일하게 바인딩하면 된다.

## 단축키

| 동작 | 단축키 |
|------|--------|
| Find Usages / Go to References | Alt + Q |
| Back | Ctrl + - |
| Forward | Ctrl + Shift + - |
| Go to Declaration or Usages | F12 |

Windows 기준이다. macOS에서는 Ctrl 대신 ⌘ 등 환경에 맞게 바꾸면 된다.
