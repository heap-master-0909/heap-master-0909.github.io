## Map / Set

ES6에서 도입된 새로운 자료구조다. 기존 Object와 Array로도 비슷한 일을 할 수 있지만, 특정 상황에서 훨씬 편리하고 성능이 좋다.

### Map/Set이 필요한 이유

| 기존 방식 | 문제점 | 대안 |
|-----------|--------|------|
| `Object`를 Map처럼 사용 | 키가 반드시 문자열/Symbol, 프로토타입 오염 위험 | **Map** |
| `Array`로 중복 제거 | `indexOf`/`includes`로 매번 검사 → 느림 | **Set** |

### Map

**키-값 쌍**을 저장하는 자료구조. Object와 달리 **어떤 타입이든 키로 사용**할 수 있다.

```javascript
const map = new Map();

// 다양한 타입을 키로 사용 가능
map.set('name', '홍길동');
map.set(1, '숫자 키');
map.set(true, '불리언 키');

const objKey = { id: 1 };
map.set(objKey, '객체도 키로 사용 가능');

console.log(map.get('name'));   // '홍길동'
console.log(map.get(objKey));   // '객체도 키로 사용 가능'
console.log(map.size);          // 4
```

#### Object와 Map 비교

| 비교 항목 | Object | Map |
|-----------|--------|-----|
| 키 타입 | 문자열, Symbol만 | **모든 타입** (객체, 함수, 숫자 등) |
| 순서 보장 | 보장하지 않음 (ES2015+부터 일부 보장) | **삽입 순서 보장** |
| 크기 확인 | `Object.keys(obj).length` | `map.size` |
| 반복 | `for...in` (프로토타입 포함 주의) | `for...of`, `forEach` |
| 성능 | 잦은 추가/삭제 시 느릴 수 있음 | 잦은 추가/삭제에 **최적화** |

#### 주요 메서드

```javascript
const userMap = new Map();

userMap.set('alice', { age: 25 });
userMap.set('bob',   { age: 30 });

userMap.has('alice');    // true
userMap.delete('bob');   // true
userMap.size;            // 1

// 반복
userMap.forEach((value, key) => {
  console.log(`${key}: ${value.age}세`);
});

// 구조 분해와 for...of
for (const [key, value] of userMap) {
  console.log(key, value);
}

userMap.clear();  // 모든 항목 삭제
```

### Set

**중복 없는 값의 집합**. 같은 값을 여러 번 추가해도 하나만 저장된다.

```javascript
const set = new Set();

set.add(1);
set.add(2);
set.add(2);  // 무시됨 (이미 존재)
set.add(3);

console.log(set.size);    // 3
console.log(set.has(2));  // true
```

#### 배열 중복 제거

Set의 가장 흔한 활용 사례다.

```javascript
const fruits = ['사과', '바나나', '사과', '딸기', '바나나', '포도'];

// Set으로 중복 제거 후 다시 배열로 변환
const unique = [...new Set(fruits)];
console.log(unique);  // ['사과', '바나나', '딸기', '포도']
```

#### 주요 메서드

```javascript
const tags = new Set(['javascript', 'node', 'react']);

tags.add('vue');          // 추가
tags.delete('react');     // 삭제
tags.has('node');          // true
tags.size;                 // 3

// 반복
tags.forEach(tag => console.log(tag));

for (const tag of tags) {
  console.log(tag);
}

tags.clear();  // 모든 항목 삭제
```

#### 집합 연산

```javascript
const a = new Set([1, 2, 3, 4]);
const b = new Set([3, 4, 5, 6]);

// 합집합
const union = new Set([...a, ...b]);           // {1, 2, 3, 4, 5, 6}

// 교집합
const intersection = new Set([...a].filter(x => b.has(x)));  // {3, 4}

// 차집합
const difference = new Set([...a].filter(x => !b.has(x)));   // {1, 2}
```

## null 병합 연산자 (??)

ES2020에서 도입된 연산자로, **`null` 또는 `undefined`일 때만** 오른쪽 기본값을 사용한다.

### falsy와 OR 연산자 (||)의 함정

`||`는 왼쪽이 **falsy**이면 오른쪽 값을 반환한다. 문제는 `0`, `''`, `false`도 falsy라는 점이다.

| falsy 값 | 설명 |
|-----------|------|
| `false` | 불리언 거짓 |
| `0`, `-0` | 숫자 영 |
| `''` | 빈 문자열 |
| `null` | 의도적으로 "값 없음" |
| `undefined` | 값이 할당되지 않음 |
| `NaN` | 유효하지 않은 숫자 |

```javascript
// || 는 falsy를 모두 걸러버린다
const port = 0 || 3000;
console.log(port);  // 3000 — 0을 쓰고 싶었는데 무시됨!

const name = '' || '기본이름';
console.log(name);  // '기본이름' — 빈 문자열도 무시됨!

const debug = false || true;
console.log(debug); // true — false를 의도했는데 덮어씌워짐!
```

### null과 undefined만 구분하는 ?? 연산자

`??`는 왼쪽이 **`null` 또는 `undefined`일 때만** 오른쪽 값을 반환한다.
`0`, `''`, `false`는 유효한 값으로 취급한다.

```javascript
// ?? 는 null/undefined만 걸러낸다
const port = 0 ?? 3000;
console.log(port);  // 0 ✅

const name = '' ?? '기본이름';
console.log(name);  // '' ✅

const debug = false ?? true;
console.log(debug); // false ✅

const value = null ?? '기본값';
console.log(value); // '기본값' ✅

const value2 = undefined ?? '기본값';
console.log(value2); // '기본값' ✅
```

### || vs ?? 비교

```javascript
function createServer(options) {
  // ❌ || 사용: port에 0을 넘기면 무시된다
  const port = options.port || 3000;

  // ✅ ?? 사용: null/undefined일 때만 기본값 적용
  const port = options.port ?? 3000;
}

createServer({ port: 0 });  // || → 3000, ?? → 0
createServer({ });           // || → 3000, ?? → 3000
```

### 옵셔널 체이닝 (?.) 과 함께 사용

`?.`는 객체 속성에 접근할 때 중간 값이 `null`/`undefined`이면 에러 대신 `undefined`를 반환한다.
`??`와 조합하면 안전하게 기본값까지 지정할 수 있다.

```javascript
const user = {
  name: '홍길동',
  address: {
    city: '서울',
  },
};

// 옵셔널 체이닝 단독
console.log(user.address?.city);     // '서울'
console.log(user.address?.zipCode);  // undefined (에러 없음)
console.log(user.phone?.number);     // undefined (에러 없음)

// ?. + ?? 조합: 값이 없으면 기본값 적용
const zip = user.address?.zipCode ?? '우편번호 없음';
console.log(zip);  // '우편번호 없음'

const phone = user.phone?.number ?? '연락처 미등록';
console.log(phone);  // '연락처 미등록'
```

> `?.` 없이 `user.phone.number`로 접근하면 `TypeError`가 발생한다.  
> `?.`와 `??`를 함께 쓰면 **에러 방지 + 기본값 지정**을 한 줄로 처리할 수 있다.
