## TypeScript란?

아주 간단히 말하면 **JavaScript에 타입(Type)이 추가**된 언어이다.
단, TS는 JS처럼 바로 런타임에서 실행되지 않고 **TS → JS 변환(컴파일) 후 실행**된다. 이 변환을 담당하는 것이 `tsc`(TypeScript Compiler)이다.

> JS의 자유로움이 대규모 프로젝트에서는 버그의 원인이 된다. TS는 **컴파일 타임에 타입 오류를 잡아** 이 문제를 해결한다.

| 구분 | JavaScript | TypeScript |
|:---|:---|:---|
| 타입 시스템 | 동적 타입 | 정적 타입 |
| 실행 방식 | 런타임 직접 실행 | tsc 컴파일 → JS → 실행 |
| 확장자 | `.js` | `.ts` / `.tsx` |
| 타입 검사 시점 | 런타임 | 컴파일 타임 |

## 설치 및 설정

```sh
# TypeScript 설치
npm i -D typescript

# tsconfig.json 초기화
npx tsc --init

# ts-node 설치 (컴파일 없이 바로 실행)
npm i -D ts-node

# 실행
npx ts-node index.ts
```

### tsconfig.json 주요 옵션

```json
{
  "compilerOptions": {
    "target": "ES2020",
    "module": "commonjs",
    "outDir": "./dist",
    "rootDir": "./src",
    "strict": true,
    "esModuleInterop": true,
    "resolveJsonModule": true,
    "declaration": true,
    "sourceMap": true
  },
  "include": ["src/**/*"],
  "exclude": ["node_modules", "dist"]
}
```

| 옵션 | 설명 |
|:---|:---|
| `target` | 컴파일 결과물의 JS 버전 |
| `strict` | 모든 엄격 타입 검사 활성화 |
| `outDir` | 컴파일된 JS 파일 출력 경로 |
| `rootDir` | 소스 파일 루트 경로 |
| `esModuleInterop` | CommonJS 모듈을 ES 모듈 방식으로 import 가능 |
| `declaration` | `.d.ts` 타입 선언 파일 자동 생성 |

## 기본 타입

### 원시 타입

```ts
const name: string = "heap";
const age: number = 30;
const isActive: boolean = true;
const nothing: null = null;
const notDefined: undefined = undefined;
```

### 배열과 튜플

```ts
const nums: number[] = [1, 2, 3];
const strs: Array<string> = ["a", "b", "c"];

// 튜플 — 각 인덱스의 타입이 고정
const tuple: [string, number] = ["heap", 30];
```

### enum

```ts
enum Role {
  ADMIN = "ADMIN",
  USER = "USER",
  GUEST = "GUEST",
}

const myRole: Role = Role.ADMIN;
```

### any / unknown / never / void

```ts
// any — 타입 검사 비활성화 (가급적 사용 금지)
let anything: any = "hello";
anything = 123;

// unknown — any보다 안전. 사용 전 타입 확인 필수
let uncertain: unknown = "hello";
if (typeof uncertain === "string") {
  console.log(uncertain.toUpperCase()); // 타입 좁히기 후 사용 가능
}

// void — 반환값이 없는 함수
function log(msg: string): void {
  console.log(msg);
}

// never — 절대 반환되지 않는 함수
function throwError(msg: string): never {
  throw new Error(msg);
}
```

## 인터페이스와 타입 별칭

### interface

```ts
interface User {
  id: number;
  name: string;
  email?: string;       // 선택적 속성
  readonly role: string; // 읽기 전용
}

const user: User = { id: 1, name: "heap", role: "ADMIN" };
```

### type

```ts
type ID = string | number;

type Product = {
  id: ID;
  name: string;
  price: number;
};
```

### interface vs type

| 구분 | interface | type |
|:---|:---|:---|
| 확장 | `extends`로 상속 | `&`(intersection)로 결합 |
| 선언 병합 | 같은 이름으로 재선언 시 자동 병합 | 불가 |
| 유니온/튜플 | 불가 | 가능 |
| 사용 권장 | 객체 구조 정의 | 유니온, 복합 타입 |

```ts
// interface 확장
interface Animal {
  name: string;
}
interface Dog extends Animal {
  breed: string;
}

// type 결합
type Animal2 = { name: string };
type Dog2 = Animal2 & { breed: string };
```

## 함수 타입

```ts
// 기본 함수 타입
function add(a: number, b: number): number {
  return a + b;
}

// 화살표 함수
const multiply = (a: number, b: number): number => a * b;

// 선택적 매개변수 & 기본값
function greet(name: string, greeting: string = "Hello"): string {
  return `${greeting}, ${name}!`;
}

// Rest 파라미터
function sum(...nums: number[]): number {
  return nums.reduce((acc, n) => acc + n, 0);
}

// 함수 타입 별칭
type MathFn = (a: number, b: number) => number;
const divide: MathFn = (a, b) => a / b;
```

## 제네릭 (Generics)

타입을 **파라미터처럼** 전달해서 재사용 가능한 코드를 만든다.

```ts
// 기본 제네릭 함수
function identity<T>(value: T): T {
  return value;
}

identity<string>("hello"); // 명시적
identity(42);              // 타입 추론

// 제네릭 인터페이스
interface ApiResponse<T> {
  success: boolean;
  data: T;
  message?: string;
}

const userRes: ApiResponse<User> = {
  success: true,
  data: { id: 1, name: "heap", role: "ADMIN" },
};

// 제네릭 제약 조건 (extends)
function getLength<T extends { length: number }>(item: T): number {
  return item.length;
}

getLength("hello");    // OK
getLength([1, 2, 3]);  // OK
// getLength(123);     // ❌ number에는 length가 없음
```

## 유틸리티 타입

TS가 기본 제공하는 타입 변환 도구들이다.

```ts
interface User {
  id: number;
  name: string;
  email: string;
  password: string;
}

// Partial — 모든 속성을 선택적으로
type UpdateUser = Partial<User>;

// Required — 모든 속성을 필수로
type FullUser = Required<User>;

// Pick — 특정 속성만 추출
type UserPreview = Pick<User, "id" | "name">;

// Omit — 특정 속성을 제외
type PublicUser = Omit<User, "password">;

// Record — 키-값 쌍의 타입 정의
type RoleMap = Record<string, User>;

// Readonly — 모든 속성을 읽기 전용으로
type FrozenUser = Readonly<User>;
```

## 타입 좁히기 (Type Narrowing)

```ts
// typeof 가드
function process(value: string | number) {
  if (typeof value === "string") {
    return value.toUpperCase();
  }
  return value.toFixed(2);
}

// in 연산자
interface Cat { meow: () => void }
interface Dog { bark: () => void }

function speak(animal: Cat | Dog) {
  if ("meow" in animal) {
    animal.meow();
  } else {
    animal.bark();
  }
}

// 사용자 정의 타입 가드
function isString(value: unknown): value is string {
  return typeof value === "string";
}
```

## 클래스와 접근 제어자

```ts
class UserService {
  private db: Map<number, User> = new Map();
  protected counter: number = 0;

  constructor(public readonly serviceName: string) {}

  addUser(name: string): User {
    const id = ++this.counter;
    const user: User = { id, name, email: "", password: "" };
    this.db.set(id, user);
    return user;
  }

  getUser(id: number): User | undefined {
    return this.db.get(id);
  }
}
```

| 접근 제어자 | 클래스 내부 | 자식 클래스 | 외부 |
|:---|:---|:---|:---|
| `public` | O | O | O |
| `protected` | O | O | X |
| `private` | O | X | X |

## 실전 예시 — Express + TypeScript

### 프로젝트 세팅

```sh
npm init -y
npm i express
npm i -D typescript ts-node @types/node @types/express nodemon
npx tsc --init
```

> `@types/xxx`는 JS 라이브러리의 타입 선언 패키지이다. TS에서 외부 JS 라이브러리를 사용하려면 필요하다.

### 기본 서버

```ts
// src/app.ts
import express, { Request, Response } from "express";

const app = express();
app.use(express.json());

interface CreateUserBody {
  name: string;
  email: string;
}

app.post("/users", (req: Request<{}, {}, CreateUserBody>, res: Response) => {
  const { name, email } = req.body;
  res.status(201).json({ id: 1, name, email });
});

app.listen(3000, () => {
  console.log("Server running on port 3000");
});
```

### 라우터 분리

```ts
// src/routes/user.route.ts
import { Router, Request, Response } from "express";

const router = Router();

router.get("/", (req: Request, res: Response) => {
  res.json({ users: [] });
});

export default router;
```

```ts
// src/app.ts
import userRouter from "./routes/user.route";

app.use("/users", userRouter);
```

### package.json 스크립트

```json
{
  "scripts": {
    "dev": "nodemon --exec ts-node src/app.ts",
    "build": "tsc",
    "start": "node dist/app.js"
  }
}
```

## 정리

| 핵심 개념 | 한 줄 요약 |
|:---|:---|
| 기본 타입 | `string`, `number`, `boolean`, `null`, `undefined` |
| 배열/튜플 | `number[]`, `[string, number]` |
| interface / type | 객체 구조 정의 / 유니온·복합 타입 정의 |
| 제네릭 | 타입을 파라미터로 받아 재사용성 극대화 |
| 유틸리티 타입 | `Partial`, `Pick`, `Omit`, `Record` 등 기본 제공 변환 도구 |
| 타입 좁히기 | `typeof`, `in`, 사용자 정의 가드로 타입 분기 |
| 접근 제어자 | `public`, `protected`, `private` |
| `@types/xxx` | JS 라이브러리의 TS 타입 선언 패키지 |
